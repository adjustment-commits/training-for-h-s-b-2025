第15回｜反応と連動

前回までに、
「方向を作る → ズレても戻す」を習得した。

ここからは、その能力を
“実際の動きの速さ”の中で使える選手へ。

反応と連動は、野球の全局面で勝負を決める。

反応とは？（野球版）

反応＝速く動くことではない。

「骨盤ラインが合った瞬間に動き出せる」こと。

投手：合った瞬間に並進へ入れる。
打者：トップ→踏み込みの“間”を感じられる。
守備：一歩目の方向を迷わず切れる。

つまり、反応は
“タイミング × 方向 × 連動”の総合能力。

体験① リアクション・スピードラン

コーチの手信号（左／右／前／後）に対して、
その方向へ一気にスプリントして即戻る。

やり方
1. アスレチックスタンスで構える（足幅は肩幅より少し広め）。
2. コーチが「左」「右」「前」「後ろ」をランダムに指示。
3. 指示方向へ2〜3歩全力でダッシュ → すぐ元の位置へ戻る。
4. 方向が変わっても、骨盤→胸→脚の順で出ているかを感じる。

狙い（野球）
・投手：クイックや牽制後もフォームを崩さず投げに入る準備。
・打者：投球タイミングがズレても、トップの位置を保ったまま反応。
・守備：打球の変化に対して、一歩目と戻りの軌道をそろえる。

8〜10本（高強度）。

※合図は手信号でも声でも可。現場に合わせて統一。

体験② MBダブルアングル・スロー

メディシンボールを使い、
コーチの「右」「左」コールに対して瞬時に方向を作って投げる。

やり方
1. 軽めのMBを両手で持ち、正面を向いて立つ。
2. コーチが「右」「左」をランダムコール。
3. コールされた側へ
　　　・骨盤を先にひねる（ヒップリード）
　　　・遅れて胸郭がついてくる
　　　・最後に腕が“流れで”MBを押し出す。
4. 腕だけで方向を変えたら失敗。骨盤で方向を決める。

狙い（野球）
・投手：リリース方向のブレを減らす。
・打者：ヒップインの方向とスイングプレーンの一致。
・守備：捕球姿勢から送球方向への切り替えを滑らかにする。

左右6〜8本 × 2セット。

※MBは1〜2kg推奨。重すぎると腕主導になりやすい。

実践① ミニハードル・カッティングダッシュ

ミニハードル3台を使い、方向転換と加速を連続で行う。

セット
・ミニハードルを約1m間隔で3台並べる。
・スタート位置はハードルの手前（横向きでも前向きでもOK）。

やり方
1. コーチが「左」「右」「前」「後ろ」をランダムでコール。
2. 指示に合わせて
　・横方向ならカットステップで1〜2歩 → すぐ前へ加速。
　　・「後ろ」のときは1歩後退 → そこから前へ爆発。
3. ハードルをまたぎながらも、骨盤→胸→脚の順で動きをつなげる。
4. リズムが止まったら連動が切れているサイン。

狙い（野球）
・内野：打球への入り → 方向転換 → 送球につなぐ一連の流れ。
・外野：落下点修正と前後の切り返し。
・投手：フィールディング時のカバーと送球までの動き。

4方向を2周（高強度）。

※ミニハードルは高さ10〜15cm。過度に高いと動きが乱れる。

実践② バンド・リアクティブヒップドロップ

前方から軽く引かれたバンドに対して、
骨盤を「落とす → 拾う → 加速」に一気につなげる。

やり方
1. バンドを骨盤に巻き、コーチが前方から軽くテンションをかける。
2. コーチの「落として」の合図で、骨盤を素早くストンと落とす。
3. 次の「上！」の合図で、骨盤を拾い上げるように立ち上がり、
その流れで3〜5m前方に加速。
4. 胸が先に突っ込んだら失敗。
常に骨盤リード → 胸 → 腕（脚）の順に動く。

狙い（野球）
・守備：低く構えた状態からの一歩目と加速。
・打者：トップからの「落とし」→「拾い」→スイングへの接続。
・投手：フィールディングでの落ち→拾い→送球の速さ。

左右3本 × 2セット（しっかり全力）。

※バンドは弱めのテンション。胸が前に出る設定はNG。

実践③ 3方向リアクションチェンジ

その場から左右 → 前 → 後ろの3方向を、
コーチの2コールに合わせて一気につなぐ。

セット
・選手を中心に、左右と後方にマーカーを置く（半径約1m）。
・前方向には3〜5mのダッシュスペース。

やり方
1. コーチが
「右 → 前」「左 → 後ろ」「後ろ → 前」など、
2ステップの指示をランダムに出す。
2. 選手は
1つ目の方向へ素早くカット → すぐ2つ目の方向へ切り替え。
3. どの組み合わせでも、骨盤が最初に向きを作り、
遅れて胸→脚がついていくかを確認する。
4. 上半身から方向を変えたらエラー扱い。

狙い（野球）
・すべてのポジションに必要な「方向転換の連続対応」。
・外野：バウンド変化や風での軌道変化への2段階反応。
・投手：バント処理や悪送球カバーなど、複数方向への素早い切り替え。

6〜8セット（高強度）。

※後方マーカーの距離は50〜80cmで調整。一歩で届く距離に。

問い

「反応が良い選手」の本質はどれ？

まとめ

反応＝速さではなく、
“骨盤ラインが整った瞬間に動ける力”。

順番が崩れない選手は、
どのプレーでも迷わず、速く、正確に動ける。
