第16回｜統合と表現

これまで身につけた
「方向」「反応」「連動」「再現」。

今日は“野球の動き”として統合する最終回。

体を整える段階から、
パフォーマンスとして表現する段階へ。

統合とは？（野球版）

統合＝一つの動作の中で
「骨盤 → 胸郭 → 腕（脚）」の順番が崩れないこと。

投げる、打つ、走る、守る。
どのプレーも“連動の質”で決まる。

体験①：ヒップスイッチ → ダッシュ結合

骨盤で方向を作り、そのまま一歩目へつなげる統合感覚。

やり方
1. その場でヒップスイッチ（左右を素早く切替）。
2. コーチの「前／右／左」コールで即ダッシュ（3〜5m）。
3. 骨盤→胸→脚の順で出られたら成功。
4. 上半身が先に突っ込んだらエラー。

狙い（野球）
・守備の一歩目の質向上。
・打者の“踏み込み方向”の精度アップ。
・投手のクイック・フィールディング改善。

体験②：MBアングルチェンジ → リリース

「方向→連動→出力」を一連でまとめる。

やり方
1. MBを持ち、正面で構える。
2. コーチが「右／左」いずれかをコール。
3. 骨盤の向きを先に作る → 胸郭が遅れてついてくる。
4. 最後に“流れで”MBを押し出す（腕主導は禁止）。
5. 投げる方向がズレたら骨盤の遅れ。

狙い（野球）
・打者：ヒップイン → スイング方向の一致。
・投手：方向のブレをなくす。
・守備：送球方向への身体のセットを素早く。

実践①：3コース連動アプローチ

真正面・右・左の3コースを、コーチの連続コールで処理する。

やり方
1. 3方向にコーンを置く（距離3〜5m）。
2. コーチが例：
「右 → 正面 → 左」
「左 → 右 → 正面」など2〜3連続の指示。
3. 骨盤が向きを作る → 胸 → 脚の順で移動。
4. 方向が変わるほど連動の精度が問われる。

狙い（野球）
・守備の入り → 修正 → 送球につながる軌道の質。
・外野の落下点修正。
・走塁のライン取り向上。

実践②：統合スイングライン（打者） or 統合フィールディング（投手・守備）

選手のポジションに合わせて「統合動作」を選択。

打者の場合
・ヒップイン →捻転 → スイング方向 → 反応。
・ティーを使い、“狙ったライン”へ連続5球。

投手・守備の場合
・入り → ステップ → 方向 → 送球までを一連で実施。
・ショートレンジ送球で軌道の安定を確認。

統合＝「再現性のあるパターン × 反応の速さ」。

問い

“上手い選手”と“強い選手”。
違いは何だと思う？

まとめ

野球の動作は
「感じる → 方向を作る → 連動する → 表現する」の連続。

その再現性が高い選手ほど、試合で“強い”。
